# Projeto Final — Web 1

Página web em HTML + CSS + JavaScript puros.

## Como rodar

Para executar a API local, edite o arquivo api/db.json e execute:

```bash
npm install 
npm run api
```

A API sobe em `http://localhost:3001`.

Se for usar a PokéAPI, pode apagar a pasta `api/` e o arquivo `package.json`.
